# 02-R1 后续试玩与技术验收清单

所有试玩以相同版本二进制/构建哈希为准。当前已经取得的是 Chrome 155 的**CSS 视口模拟**和少量键盘输入，并不构成真机试玩。

| 检查对象 | 已测 Chrome 技术结果 | 仍需真实试玩/补证 |
|---|---|---|
| 360×800 竖屏 | 首屏全画布；无横向溢出；两列控件左对齐 | HUD 小字能否读懂；点击/触屏路径；实际设备 DPI |
| 390×844 竖屏 | 首屏全画布；控件 177px × 42px | 42px 高度低于常用 44px 触控目标参考值，需实际操作审查 |
| 844×390 横屏 | 首屏全画布；控件间距≥12px | 长文案/系统字体缩放时是否挤压；真实横屏旋转 |
| 1280×900 桌面 | 游戏加载、键盘输入、页面错误检查通过 | 完整关卡 1–3 可玩性与状态准确性 |
| 预测落点/移动轨道/警告 | 未覆盖完整状态集 | 同场景复现预测目标、移动轨道、不能生成警示的语义一致性和小屏辨识 |
| 长时间运行与真机 | 未运行 | iOS/Android、浏览器焦点、触控、性能、横竖切换、可访问性 |

**试玩流程建议**：固定浏览器/设备、版本/commit、视口、字号与输入；先正常通关，再逆向操作/长文案/低亮度/横竖屏切换；记录被遮挡或误读对象、截图 SHA、错误日志、测试者原话；每一条缺陷都标示 severity 与复现路径。真人偏好判定与技术通过分开保管。
