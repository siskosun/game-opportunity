# ET-VISUAL-02：竖屏触控 T2 用户复评包

**目标**：修复你反馈的“横屏没问题，竖屏操作很反人性”。

**区别**：原 T1 将五个键全部排在一行，左右手目标交叉。新 T2 竖屏分为左右拇指区，左手按住左/右移动，右手点击跳跃（更大）和冲刺，低频锚定在右上方。横屏代码与布局不变；game.js / render.js / 关卡均无变更。

## 查看截图

直接打开 `review.html`；文件可以离线查看。

## 真机试玩

解压本包后在文件所在目录打开命令行：

```
py -m http.server 8765 --bind 0.0.0.0
```

如果 Windows 没有 `py`，可执行 `python -m http.server 8765 --bind 0.0.0.0`。电脑浏览器打开 `http://127.0.0.1:8765/playable-t2/`。手机连接同一 Wi-Fi 后用 `http://电脑局域网IP:8765/playable-t2/`。尽量在可信局域网操作。关闭命令行即停止共享。

## 已验证（不是人因验收）

- GitHub Actions Chrome 155 真实触摸事件模拟、四个移动视口（360×640、360×800、390×844、844×390）与 1280×900 桌面。
- 69 项原游戏测试、7 项触控单元测试以及原 R2 状态语义检查通过。
- 浏览器模拟双指移动+跳跃、空中冲刺、手指抬起/取消、页面切换与选关；零控制遮挡、零页面横向溢出、零 JavaScript/网络请求错误。
- 竖屏两个操作区之间至少 24 CSS px 留白，主跳跃键不小于 68×72 CSS px，44px 及以上辅助按键，底部操作区不盖住画布。
- 横屏原有按键的左右两侧像素与 T1 基线截图完全相同；中心游戏动画存在时间差，不能要求全画面像素恒同。
- 新版 JS 文件 SHA-256 与 T1 完全相同，只修改 `index.html` 竖屏 CSS。完整证据见 `proof/touch-qa-report.json`。
