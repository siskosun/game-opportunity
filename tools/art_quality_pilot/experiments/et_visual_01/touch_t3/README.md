# ET-VISUAL-02：T3 横屏优先方案（等待操作复评）

## 为什么不再扩展竖屏按键

用户反馈原话：**“操控面积太小了，竖屏不适合这种虚拟按键的方式”**。T1 五键同排已被否定，T2 虽然改为双拇指分区，依然没有解决竖屏操作空间不足的问题。因此**不把 T2 的自动化测试通过视作人因通过**。

## T3 解决方式

- 手机竖屏（触控、宽度≤580 CSS px）：显示“横过手机，开始跳跃”的全屏引导。五个虚拟按钮隐藏，游戏暂停；将手机旋转横屏即可继续。
- 手机横屏：**严格保留**用户认可的 T1 两侧按钮、顶部工具栏和 R2 画面，原布局区域对照截图差异为 0 像素；游戏不重开，继续原有状态。
- 桌面：键盘操作不变。**不使用强制旋转、浏览器全屏或未经授权的系统设置**。如系统禁止自动转屏，用户需解除旋转锁定。
- 源版 Echo Tide、R2 基线归档、T1/T2 历史包均未覆盖。游戏核心、关卡、碰撞等源代码未修改。

## 查看和试玩

打开同目录 `review.html` 可离线查看新旧竖屏与横屏截图。

在本压缩包解压目录的终端运行：

```bash
python -m http.server 8765 --bind 0.0.0.0 --directory playable-dist
```

Windows 可以使用 `py -m http.server 8765 --bind 0.0.0.0 --directory playable-dist`。电脑浏览器访问 `http://127.0.0.1:8765/`；手机与电脑位于**同一可信 Wi-Fi** 时，手机浏览器访问 `http://电脑局域网IP:8765/`。试用后停止服务器，不要暴露到公网。这里包含的是 CI 验证时的原始构建，未更改 HTML/JS 的最终产物。
