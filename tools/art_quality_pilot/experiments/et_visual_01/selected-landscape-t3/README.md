## Windows / 手机实际试玩

1. 解压压缩包到电脑某个目录。
2. 在解压目录打开 PowerShell，运行：
   `py -m http.server 8765 --bind 0.0.0.0 --directory playable-dist`
3. 用电脑浏览器访问 `http://127.0.0.1:8765/`。
4. 手机和电脑连入**同一个可信 Wi-Fi**，用手机浏览器访问 `http://电脑局域网IP:8765/`。
5. 竖屏会显示“横过手机，开始跳跃”；横屏后出现已认可的两侧控制区。如果无法转屏，请检查系统的旋转锁定设置。
6. 试用后结束服务器；不要把本地测试服务暴露到公网。

如 8765 端口被占用，可使用其他端口，但请以实际端口替换上述地址。运行前先通过 `py verify.py` 核对随包构建文件。
