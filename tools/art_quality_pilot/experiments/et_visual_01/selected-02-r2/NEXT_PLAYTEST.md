# 以 02-R2 为新基线的下一轮工作

1. **先解决实质性输入缺口**：原游戏仍然依赖键盘移动、跳跃、冲刺与锚定；在真手机浏览器中缺少可靠的移动/跳跃触控控件。先做独立可回退的触摸控制方案，不修改玩法的规则与数值；至少覆盖左右移动、跳跃、冲刺、锚定及重试。不得将 CSS 模拟视口等同于真机交互。
2. **浏览器玩家级回归**：验证 360×800、390×844、844×390、1280×900；录制控件状态、画布框、可见文字、控制台/失败请求；预告落点、移动轨道、轨道上升/消失、边界不能生成、死亡和三关完成均使用生产规则计算并明确记录合成夹具。
3. **真实设备补证**：至少 iOS Safari 和 Android Chrome 各一台，测试触摸冲突、屏幕旋转、软键盘与系统缩放、安全区域、60 秒连续操作及误触。
4. **对每个新版本保留可回退来源**：同时记录 Git SHA、构建 HTML/JS SHA、截图 SHA、失败/成功输入轨迹与评审意见。后续视觉变化仍需用户再评判，不自动继承本次“R2更好”的批准范围。
